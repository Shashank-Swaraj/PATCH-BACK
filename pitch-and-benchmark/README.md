# 📊 Integration, Benchmark & Pitch (`pitch-and-benchmark/`)

**Owner:** Nikitah (`feature/pitch-benchmark` branch)

## What this module does:
This folder contains everything needed to pitch our hackathon project to the judges:
* `slides-outline.md`: The complete 5-slide outline ready to paste into Canva / PowerPoint.
* `pitch-script.md`: The exact 3-minute oral script divided among team members.
* `benchmark-runner.js`: The official evaluation runner that prints our 100% detection rate and 0% false positives scorecard.

## How to run the benchmark:
```bash
node pitch-and-benchmark/benchmark-runner.js
```
